## Priority Issues

**[P1] Carousel slide changes are invisible to screen reader users.**
- **Why it matters:** `<p class="photocarousel__status" aria-hidden="true">` hides the visible "X / 7" counter from assistive tech, and there's no `aria-live` region tied to slide-index changes. A screen-reader user pressing the arrow keys or prev/next buttons (confirmed working for sighted users) gets no auditory confirmation of which photo is now showing.
- **Fix:** Either drop `aria-hidden="true"` from `.photocarousel__status` and make it `aria-live="polite"`, or add a visually-hidden `aria-live="polite"` sibling announcing "Photo X of 7" on every slide change — the same pattern already used for the disabled-control live announcer in `main.js`.
- **Suggested command:** `/impeccable harden`

**[P2] Footer "Navigate" column and primary nav both promise navigation and deliver exactly one link.**
- **Why it matters:** A column headed "NAVIGATE" holding a single "About Us" item, on a page where the top nav similarly shows only one live destination among four items, reads as premature rather than intentional. Direct consequence of the site's (defensible) launch-gating strategy, but the label oversells the content.
- **Fix:** Either drop the "Navigate" heading until a second link exists, or add a quiet line ("More pages soon") so the heading doesn't imply a menu that isn't there yet.
- **Suggested command:** `/impeccable clarify`

**[P2] Locked Login/Donate pills remain the page's most visually assertive top-right elements at a glance.**
- **Why it matters:** Already iterated once (flattened gradients, lock glyph, toast) — remaining risk is specifically touch/first-time users: the `title` tooltip never fires on touch, and the `.locked-tip` toast only shows ~2.2s, an easy window to miss on a glance-away.
- **Fix:** Lengthen the toast duration slightly, or add a brief non-blocking inline state change (e.g. a border pulse) for a more forgiving feedback window.
- **Suggested command:** `/impeccable polish`

**[P3] Copy register mismatch in the quickfacts band.**
- **Why it matters:** "34th FACT Conference," "1,200+ Attendees," "26 Schools" read as substantive and specific; "3 / Days of Fun" reads generic by comparison — the one quickfact that could belong to any event.
- **Fix:** Match the register, e.g. "Days of Programming" or "Days at UIUC."
- **Suggested command:** `/impeccable clarify`

## Persona Red Flags

**Sam (accessibility-dependent):** The P1 finding above is the concrete one — carousel navigation with no live-region feedback on slide position. Minor secondary note: the dot list uses `role="tablist"`/`role="tab"` but each dot sits independently in normal Tab order rather than the ARIA APG roving-tabindex-plus-arrow-keys pattern for tabs — functional, but not canonical.

The lock glyph and dimming are legitimate mitigations, but a fast scanner on a touch device could still tap "Donate" expecting it to work and get only a brief toast as explanation.
