### Design Specificity Verdict

**LLM assessment (A):** Mostly bespoke, one real seam. Content is unmistakably FACT/UIUC-specific — MTD orange-vs-white bus stops, Foellinger bag policy, "IllinoisNet_Guest," a hotel block competing with a football weekend, Tagalog theme phrase "Ipahayag nang Malakas." Not template-with-copy-swapped.

Seam: the decorative vocabulary (moon phases, orbit ring, botanical vine, butterfly, "almanac held to candlelight") is generic Western witchy-almanac, not Filipino. No parol, sarimanok, banig-weave, jeepney/capiz motifs. "Mahiwagahan" (enchantment) illustrated with a register that'd work unchanged for a tarot startup. Shell + content = FACT's own. Ornament layer = "enchanted conference," not "Filipinx enchanted conference."

**Deterministic scan (B):** CLI detect.mjs on all 7 HTML files: 0 findings, exit 0, verified genuine (sanity-tested against a deliberately-bad fixture, which correctly fired). Consistent with earlier session's audit — that scan's real findings (color/font-size drift) sat entirely in CSS, not markup; B was correctly scoped to markup only.

Live browser overlay (separate ruleset — ai-color-palette, low-contrast, text-overflow, cream-palette, gradient-text, monotonous-spacing, marquee, text-occlusion) fired more, and mostly wrongly:
- False positive, low-contrast on hero text (every page): measured against a fallback #ffffdd background-color property, not the actual dark photo/scrim behind it.
- False positive, marquee (index/faq/agenda/team): zero marquee tags or horizontal-loop keyframes anywhere in source. Detector likely re-scanning its own scrolling overlay banner.
- False positive, text-occlusion on team.html: flagged string is literally the overlay's own tooltip label sitting on the h1 — self-referential bug.
- Real, worth checking: text-overflow ×5 on index.html — span.toc__index (the 01–06 numerals) overflowing 18–34px. Neither Assessment caught this from source reading.
- ai-color-palette and monotonous-spacing fired repeatedly but likely low-confidence given the CLI scan (checked directly against DESIGN.md tokens) found zero violations in the same files.

**Overlays:** browser session was closed before this report; no live tab remains. Screenshots (desktop 1280px only — resize_window didn't actually resize the viewport for either assessment, so no true mobile capture exists) showed no visible layout breakage, overflow, or crowding across index/workshops/faq/agenda/team.

### Overall Impression

Site punches above a student-org budget — real typographic craft, honest placeholder discipline, genuine institutional depth in the FAQ. Biggest single problem: every CTA on the entire site is permanently dead, and there's not even a low-friction fallback (email capture) to catch a persuaded visitor.

### What's Working

1. A real visual system, not a template. Night→day→night rhythm, Fraunces/Jost pairing with variable-font settings, italic pulled-quote device, hand-drawn SVG motifs — consistent across all 7 pages, verified in source and live screenshots.
2. Disclosed placeholders, not fabricated ones. .team__name--tbd renders "Name TBD" in dim italic, not a fake photo; .faq__flag marks stale pricing; .section__intro flags illustrative content up front.
3. Real lived institutional knowledge in the FAQ. Foellinger bag policy, MTD bus-stop color coding, exact campus wifi network name.

### Priority Issues

**[P0] Zero working conversion action anywhere on the site**
Why it matters: Login, Donate, 9× Register, 3× View Booklet, footer "Register for FACT 2026" — all permanently aria-disabled. A maximally persuaded visitor still leaves with nothing captured, not even an email.
Fix: add one real working action — "notify me when registration opens" email capture — make it the actual primary CTA in the footer.
Suggested command: /impeccable onboard (or /impeccable clarify for copy alone)

**[P1] Undefined FACT-specific event names break comprehension**
Why it matters: agenda.html lists "Delegate Day," "Palenke," "V-Show," "Bye-Bye Brunch" with zero definition anywhere, FAQ included.
Fix: one-line descriptor per Agenda entry, reusing the TOC's existing teaser-copy pattern, or link each term to a FAQ entry.
Suggested command: /impeccable clarify

**[P1] Placeholder surface area stacks up and undercuts credibility**
Why it matters: Team 10/10 names "TBD," Workshops 9/9 sessions illustrative (with fabricated urgency), Past FACTs 2/3 years "Theme TBD." Stacked across 7 pages, skeptical visitor reads "not ready" over "exciting."
Fix: populate highest-trust placeholders first (Team directors typically lock in earliest). Consider swapping invented Workshop titles for real past-year titles, honestly labeled.
Suggested command: /impeccable clarify

**[P2] Team grid dead space at desktop widths**
Why it matters: .team__grid (repeat(auto-fill, minmax(170px, 1fr))) inside a 1180px container, 2 members per committee, stretches columns — confirmed live at 1440px, ~60-70% of the row empty.
Fix: justify-content: start + fixed item basis instead of 1fr stretch.
Suggested command: /impeccable layout

**[P2] Workshop "Register" pills + fake scarcity contradict the site's own described flow**
Why it matters: FAQ says registration is single-portal, workshop pick happens after via dashboard. Workshops page gives each of 9 sessions its own pill + invented "spots left" counts.
Fix: keep disclosure, drop the pill+counter treatment for plain "opens with registration" text.
Suggested command: /impeccable clarify

**[P2] TOC index numerals overflowing (detector-caught, unverified by source read)**
Why it matters: span.toc__index on index.html flagged by the live browser overlay as overflowing 18-34px, 5 instances.
Fix: check .toc__index sizing/line-height in css/sections.css against its container at the affected widths.
Suggested command: /impeccable audit
